# RentSaathi — Product Context

## Project Name

RentSaathi

---

## Positioning

A trust-first rental marketplace for Alwar, Rajasthan.

---

## Goal

Help users discover verified rental properties from owners and trusted brokers using a simple WhatsApp-first experience.

---

## Core Product Rules

- Mobile-first
- English-only UI
- WhatsApp CTA everywhere
- Trust badges visible
- No clutter
- Locality-first browsing
- Rental-only marketplace
- Owners and brokers both allowed
- Admin approval required before listings go live

---

## Target Audience

- Tier-2/Tier-3 Indian users
- Non-technical property owners
- Local brokers
- Rent seekers

---

## Brand Feel

- Warm
- Trustworthy
- Local
- Clean
- Fast

---

## Avoid

- Luxury corporate UI
- Dark UI
- Overloaded filters
- Generic property template feel

---

## Primary Pages

- Homepage
- Listing page
- Property detail page
- Add property page
- Dashboard
- Admin panel
